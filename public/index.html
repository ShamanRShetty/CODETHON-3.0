[ System Design ]

Cryptographic Architecture

Deterministic 6-stage access pipeline and zero-plaintext storage design.

01

Key Generation

Node.js crypto generates unique 256-bit random key and 96-bit IV per file.

02

AES-256-GCM

Ciphertext written with 128-bit authentication tag to prevent tampering.

03

Key Wrapping

File key is encrypted using MASTER_KEY; ephemeral key is wiped from memory.

04

Strict Attachment

File decrypted on the fly and served with mandatory attachment headers.

Technical Specifications

What occurs when an unauthorized person visits a share link?

They are prompted for their email address. If they are not on the recipient list, zero OTP code is emitted, their attempt is denied with a generic 404, and the attempt is logged with IP and timestamp into download_logs.

Are raw tokens ever stored in the database?

No. Only the SHA-256 hash of the 32-byte cryptographically random token is stored. The raw token is presented once upon creation.

How is instant revocation handled?

Revoking a share sets revoked_at immediately in SQLite. All future requests fail the access check and log reason REVOKED.
